How to install RGS Power-Ups in GoHighLevel (Custom JS)

Add the one-line RGS Power-Ups install to your GoHighLevel agency's Custom JS, or use the bookmark when you can't edit Custom JS.

Step by step

Install Power-Ups in HighLevel

  1. In RGS Tools, open Power-Ups and click Copy next to the install line.
  2. In HighLevel, switch to your agency view and open Settings, Company, White Label, then Custom JS.
  3. Paste the line at the very bottom, below anything already there. Don't change or remove existing code.
  4. Click Save changes and refresh HighLevel.
  5. Can't edit Custom JS? Drag the RGS Power-Ups bookmark to your bookmarks bar and click it on any HighLevel page.
