How to turn on RGS Power-Ups and choose sub-accounts

Switch RGS Power-Ups on, limit each one to the sub-accounts you pick, and see File Preview and Note Sync in action in GoHighLevel.

Step by step

Turn Power-Ups on and choose sub-accounts

  1. Every Power-Up has its own switch. Turn on the ones you want.
  2. A Power-Up runs on all your sub-accounts by default. Click the button next to the switch to pick only the sub-accounts it should run on.
  3. File Preview: hover a file on a contact to preview it, or click to open it in the page. Works on file fields and the Documents panel.
  4. Note Sync: copies each contact's notes into Latest Note and All Notes. Switch it on, pick your sub-account, then open Status and backfill and click Backfill for contacts that already have notes.
  5. Changes save on their own and show in HighLevel within a minute. Refresh the page.
Transcript

Every Power-Up has its own switch. Read the description, then turn on the ones you want. By default a Power-Up runs on all your sub-accounts. Click the button next to the switch to pick just the sub-accounts it should run on. That's handy for testing on one account first. For example, File Preview. Hover a file on a contact to preview it, or click to open it right there, without a new tab. It works on file fields and the Documents panel. Note Sync copies each contact's notes into two fields, Latest Note and All Notes, so you can use them in workflows, texts, emails and sheets. Switch it on, pick your sub-account, then open Status and backfill and click Backfill to fill in contacts that already have notes. In a workflow, pick Latest Note or All Notes from the merge-field picker, like any other field. Changes save on their own and show up in HighLevel within a minute. Just refresh the page.
